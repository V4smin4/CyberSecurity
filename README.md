# Cybersecurity Training CTF Database

## Project Overview

This project is a Cybersecurity Training Capture The Flag (CTF) Database developed using Oracle Database.

The system manages users, roles, cybersecurity challenges, teams, submissions, hints, training sessions, and audit logs.

It demonstrates Oracle SQL and PL/SQL concepts including:

- Database Design
- Constraints
- Relationships
- SQL Queries
- Views
- Stored Procedures
- Functions
- Triggers
- Packages
- Oracle DBA Commands
